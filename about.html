About Student Task Manager

A simple web application designed for students.

About the System

Student Task Manager is a web-based application that helps students organize and manage their academic activities.

Users can add tasks, assign due dates and priorities, edit tasks, delete tasks, and mark tasks as completed.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • Bootstrap 5
  • Local Storage
